# 透光浮雕 STL 生成器
好肥美，中学生第一次做，加油
一个可以把普通图片转换为 3D 打印透光浮雕模型的网页工具。上传图片后，工具会根据图片明暗生成不同厚度的浮雕表面，并导出可直接导入切片软件的 STL 文件。

透光浮雕，也叫 Lithophane，适合配合背光灯、窗边自然光或灯箱展示。图像中的深色区域会被转换为更厚的模型区域，浅色区域会转换为更薄的区域；当光从背后照射时，原图细节会重新显现出来。




功能特点

- 在浏览器中选择图片并即时生成灰度预览
- 支持设置成品宽度和高度，高度可按图片比例自动计算
- 支持调整最薄处、最厚处和边框宽度
- 支持控制最大图像采样分辨率，平衡模型细节和文件大小
- 一键生成并下载二进制 STL 文件
- 图片只在本机浏览器中处理，不会上传到服务器
- 附带 Python 命令行脚本，适合批量处理或离线自动化生成

使用方法

1. 打开网页。
2. 点击“选择图片”，导入一张照片或插画。
3. 设置模型尺寸、厚度范围、分辨率和边框。
4. 查看右侧灰度预览。
5. 点击“生成并下载 STL”。
6. 将下载的 STL 文件导入切片软件，设置打印参数后打印。

参数说明

| 参数 | 说明 | 建议值 |
| --- | --- | --- |
| 成品宽度 | 模型主体区域的宽度，单位为 mm | 80-150 |
| 成品高度 | 留空时按原图比例自动计算 | 留空 |
| 最薄处 | 浅色区域对应的最小厚度 | 0.6-0.8 mm |
| 最厚处 | 深色区域对应的最大厚度 | 2.2-3.0 mm |
| 最大分辨率 | 生成 STL 时使用的最大图像采样尺寸 | 100-200 |
| 边框宽度 | 模型四周平整边框宽度 | 2-5 mm |


、灯带或窗边自然光。
- 照片建议先裁剪成主体清晰、对比度较高的版本。



网页版本完全在浏览器本地运行，图片不会上传到任何服务器。生成过程不需要联网，适合处理个人照片或不希望外传的图片。

适用场景

- 纪念照片透光摆件
- 灯箱装饰
- 个性化礼物
- 3D 打印教学演示
- 图像转高度图实验
